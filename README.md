# 📦 **Gemini Agents Collection**

A curated collection of powerful and modular **Gemini Agents**, designed for development, automation, SEO, analysis, content creation, and multi-domain workflows.
Inspired by the philosophy behind *[TRAE Agents](https://github.com/HighMark-31/TRAE-Agents)*, this collection offers ready-to-use Gemini Agents accessible with a single click.

---

## 🚀 **Agents List**

### **1. [GEM-Developer](https://gemini.google.com/gem/1_VfvcU4redLHIxJQnMEeqoCJQMf35Jh7?usp=sharing)**

Clean and ready-to-use code generation for frontend, backend, APIs, components, debugging, and full-stack workflows.

---

### **2. [GEM-SEO](https://gemini.google.com/gem/1M1WHfJ2oZCwXX-6d4QxNFFcaJ_cafEyK?usp=sharing)**

Optimizes pages, generates SEO-rich content, analyses competitors, audits websites, and creates metadata.

---

### **3. [GEM-Compare](https://gemini.google.com/gem/1Tndkxa7Fbbe5JccsEfaxs4VmPAgz0pp1?usp=sharing)**

Creates comparison articles (e.g., “Gemini vs ChatGPT”), feature matrices, pros/cons tables, and structured SEO content.

---

### **4. [GEM-Vision](https://gemini.google.com/gem/1szoXPIW0_DG-WlbXWZ7HafjqWRL3QZUo?usp=sharing)**

Analyzes images, interprets screenshots, explains UI, detects issues, proposes improvements, and processes visual data.

---

### **5. [GEM-Marketing](https://gemini.google.com/gem/1eYTCZ9BQQkKOUOpcNkgVNAQk35xPjf61?usp=sharing)**

Generates marketing strategies, funnels, landing pages, ads, messaging, and audience positioning.

---
